# ⚔️ RPG de Mesa

Simulador de combate por turnos em Python, inspirado em sistemas de RPG de mesa. Os jogadores são cadastrados com atributos como vida, armadura e dano de arma, e batalham entre si em rodadas com resultado calculado por dados.

## 🎯 Objetivo

Projeto criado para praticar lógica de programação em Python, aplicando:

- Laços de repetição e estruturas de decisão
- Dicionários e listas para armazenar dados dos jogadores
- Organização de código em módulos (pasta `biblioteca`)
- Validação de entrada do usuário

## 📁 Estrutura

- `RPG.py` — arquivo principal, roda o jogo
- `biblioteca/` — funções auxiliares usadas no jogo
- `base de dados mach 01.py` — versão alternativa/mais simples do sistema de batalha

## 🕹️ Como rodar

```bash
pip install tabulate
python RPG.py
```
